# Артефакты репозитория

Сюда складываются **сохранённые отчёты, аудиты и одноразовые планы** — то, что
не является исполняемым кодом и не нужно в EB-бандле.

| Подкаталог | Содержимое |
|------------|------------|
| `analytics/` | CSV/JSON/Markdown из продуктовых и data-аудитов (например `scripts/analytics/`) |
| `plans/` | Черновики и дорожные карты, не вошедшие в `docs/` |
| `ops/` | Снимки планов разовых операций (cleanup, backfill, …) |
| `ads/` | Yandex Direct: `state.json`, локальный `audit.jsonl` ([`ads/README.md`](ads/README.md)) |

**Не сюда:** `docs/` (живая документация), `agents/` (инструкции для агентов),
`var/` (локальный runtime-кэш, частично в `.gitignore`).

Новые артефакты клади в подходящий подкаталог с датой или версией в имени файла.
