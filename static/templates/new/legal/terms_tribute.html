Одна успешная покупка соответствующего цифрового товара дает право выбранной команде один раз участвовать в платной турнирной интеллектуальной игре «Десяточка».

2. Цена и льгота

Фактическая цена и валюта фиксированного товара (EUR или RUB) показываются на странице оплаты до перехода в Tribute. Для обычного и подтвержденного школьного/студенческого тарифа используются разные товары. Количество через этот маршрут всегда равно одному билету.

3. Идентификация и подтверждение

До перехода в Tribute покупатель входит в Inter Oves, выбирает свою команду и подтверждает Telegram через бота. Tribute может предложить вход через Telegram или email. Автоматическое начисление возможно только если подписанное подтверждение Tribute содержит Telegram ID, ранее подтвержденный для аккаунта Inter Oves, и соответствует единственному активному намерению оплаты этого товара.

Username Telegram не используется как постоянный идентификатор. Если Tribute не передал Telegram ID или покупка совершена напрямую без созданного на сайте намерения оплаты, платеж сохраняется для ручной проверки. Для проверки напишите на {{ support_email }} и укажите Tribute purchase ID или transaction ID.

4. Момент оплаты и выдача

Переход браузера или возвращение на сайт не подтверждают оплату. Источник подтверждения — подписанный webhook Tribute. После его проверки один билет автоматически начисляется выбранной команде; повторная доставка того же purchase ID не создает второй билет.

5. Возвраты

Правила отказа и возврата указаны на общей странице возвратов. API-отмена Digital Product официально поддерживает автоматический возврат только для покупок через Telegram Stars. Возвраты карточных покупок Tribute оформляются через поддержку вручную; для идентификации сохраняются purchase ID и transaction ID.
